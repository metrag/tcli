# tcli — функции к реализации

Задача библиотеки: данные + исполнение + механика безопасности для бота-скальпера.
Торговый профиль: **акции MOEX, лонг, без плеча, без ТП (выход по SL / сигналу / EOD),
дневная (10:00–18:40) и вечерняя (19:05–23:50) сессии, ТФ 1м/5м/15м/1ч/4ч.**

Приоритеты: **P1** — скорость/надёжность, **P2** — позже.

**Итого: 11 позиций** для реализации.

## Вне scope (принцип «осознанного минимума»)

- стратегии, индикаторы, генерация сигналов;
- бэктестер, оптимизатор, walk-forward;
- риск-политика (процент риска, дневной лимит, максимум позиций) — конфиг бота, не библиотеки;
- LLM, алерты/уведомления.

## Контракт — проверочные вопросы к каждой новой функции

1. Есть `--json` и стабильная схема ответа?
2. Ошибка — это код (`INSUFFICIENT_FUNDS`…), а не текст?
3. Время явное: UTC или MSK — и одинаково везде?
4. Один вызов = одно действие; «вход+SL» — атомарно или документированной последовательностью с откатом?
5. CLI — тонкая обёртка над skills; бот зовёт skills напрямую (не subprocess).
